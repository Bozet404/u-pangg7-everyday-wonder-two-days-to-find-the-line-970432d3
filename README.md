## What it does

`main.py` writes one sentence — at most 200 characters — to `/output/entry.txt`.
The sentence is about a small everyday moment: a spider rebuilds its web
across the narrator's doorway overnight, and in the morning the narrator
has to duck under somebody else's architecture just to reach their own
kitchen. An ordinary doorway becomes a building the narrator did not design.

## Run it

```sh
python3 main.py
```

The program creates `/output` only if it is missing and writes the sentence
as UTF-8 text with no trailing newline.
